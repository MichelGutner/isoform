# Security policy

## Supported versions

Only the latest release line on npm receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub: **Security → Report a vulnerability** on [MichelGutner/isoform](https://github.com/MichelGutner/isoform/security/advisories/new).

Include the version, the platform (iOS, Android, web), steps to reproduce and the impact you expect. You will get an answer within 7 days; once a fix ships, the advisory is published with credit, if you want it.
