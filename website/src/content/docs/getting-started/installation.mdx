---
title: Installation
description: Install Isoform in an Expo app, a bare React Native app, or a web app with Vite or Next.js.
---

import { Tabs, TabItem, Steps, Aside } from '@astrojs/starlight/components';

```bash
npm install @michelgutner/isoform
# or
yarn add @michelgutner/isoform
```

Isoform's peer dependencies are `react >= 18` plus **one** platform:

| Target | Install |
|---|---|
| Web | `react-dom >= 18` |
| Mobile | `react-native >= 0.76` |

Both `react-dom` and `react-native` are optional peers, so a web app never needs React Native and a mobile app never needs React DOM. `react-native-svg` (`>= 15`) is an optional peer too, needed only by the [SVG module](/modules/svg/) on mobile.

## Set up your app

<Tabs syncKey="platform">
  <TabItem label="Expo">
    <Steps>
    1. Install the package:

       ```bash
       npx expo install @michelgutner/isoform
       ```

    2. Create the config file (see [Quick start](/getting-started/quick-start/)) and import it **first** in your root layout, before anything renders:

       ```tsx title="app/_layout.tsx"
       import '../isoform.config';
       ```

    3. If you use [optional modules](/getting-started/configuration/), add `isoform.config.json` next to `package.json`, wrap the Metro config, and rebuild the native app (`npx expo prebuild` / `npx expo run:ios`):

       ```js title="metro.config.js"
       const { getDefaultConfig } = require('expo/metro-config');
       const { withIsoform } = require('@michelgutner/isoform/metro');

       module.exports = withIsoform(getDefaultConfig(__dirname));
       ```
    </Steps>
  </TabItem>
  <TabItem label="Bare React Native">
    <Steps>
    1. Install the package and the iOS pods:

       ```bash
       yarn add @michelgutner/isoform
       cd ios && pod install
       ```

    2. Import your config file first in `index.js`:

       ```js title="index.js"
       import './isoform.config';
       import { AppRegistry } from 'react-native';
       import App from './App';

       AppRegistry.registerComponent('MyApp', () => App);
       ```

    3. With optional modules, add `isoform.config.json` at the app root and wrap the Metro config:

       ```js title="metro.config.js"
       const { getDefaultConfig } = require('@react-native/metro-config');
       const { withIsoform } = require('@michelgutner/isoform/metro');

       module.exports = withIsoform(getDefaultConfig(__dirname));
       ```

       Run `cd ios && pod install` again whenever `isoform.config.json` changes.
    </Steps>
  </TabItem>
  <TabItem label="Web (Vite)">
    <Steps>
    1. Install the package with React DOM:

       ```bash
       npm install @michelgutner/isoform react react-dom
       ```

    2. Import your config file first in the entry:

       ```tsx title="src/main.tsx"
       import './isoform.config';
       import { createRoot } from 'react-dom/client';
       import { App } from './App';

       createRoot(document.getElementById('root')!).render(<App />);
       ```
    </Steps>

    Vite resolves Isoform's web provider on its own. No plugin is needed: each optional module is a separate chunk, downloaded only when the module is on and one of its components renders.
  </TabItem>
  <TabItem label="Web (Next.js)">
    <Steps>
    1. Install the package with React DOM:

       ```bash
       npm install @michelgutner/isoform react react-dom
       ```

    2. Isoform components render on the client. Import the config file at the top of a client entry that wraps your tree (for example a `'use client'` providers file used by the root layout), so `configure()` runs before the first render.

    3. To server-render the styles, collect them with [`getStyleText()`](/guides/server-side-rendering/) and inject them into a `<style>` tag.
    </Steps>
  </TabItem>
</Tabs>

<Aside type="caution" title="Import the config before anything renders">
Components can be **defined** before `configure()` runs (they only store a primitive name), but `configure()` must run before the first **render**. Import the config file at the very top of the app entry.
</Aside>
