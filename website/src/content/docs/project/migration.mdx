Isoform is the continuation of `react-native-stylized` (later developed as `omnistyle`). Existing React Native code keeps working; going universal is incremental.

<Steps>

1. **Swap the package**: install `isoform` and replace `from 'react-native-stylized'` with `from 'isoform'`.

   ```bash
   npm uninstall react-native-stylized
   npm install isoform
   ```

2. **Drop the subpath**: the `react-native-stylized/react-native` subpath is gone. Everything comes from the root entry.

3. **Check the peers**: `react-native` is now `>= 0.76` and **optional**, together with `react-dom`. `paddingInline` and `boxShadow` need React Native ≥ 0.76.

4. **Prefix your conditions**: conditions now carry a prefix. Unprefixed ones never match and warn in development.

   | Before | After |
   |---|---|
   | `when('ios')`, `when('web')` | `when('platform:ios')`, `when('platform:web')` |
   | `when('hover')`, `when('pressed')` | `when('state:hover')`, `when('state:pressed')` |
   | `when('md')`, `when('<md')` | `when('breakpoints:md')`, `when('breakpoints:<md')` |
   | `when('variant:ghost')`, `when('disabled')` | `when('props:variant=ghost')`, `when('props:disabled')` |

5. **Fix partial matches**: `when('key:value')` used a substring match (`'status:active'` matched `'inactive'`). Prop conditions are now an exact match.

6. **Go universal when you are ready**: move to the neutral primitives (`Box`, `Input`, `Scroll`, `Pressable`…) and the standard CSS names (`paddingInline`, `boxShadow`…). The React Native names (`View`, `TouchableOpacity`, `shadow*`, `elevation`…) keep working as deprecated aliases, and your editor shows the replacement.

</Steps>

## Coming from `omnistyle`

The native classes were renamed with the package: the config file is `isoform.config.json`, the pod is `isoform`, the iOS classes use the `Iso*` prefix and the Android package is `com.isoform`. After upgrading, rename your config file, run `cd ios && pod install`, and rebuild the native app.

## What changed underneath

- `StyleSheet.flatten` was replaced by a platform-independent `flattenStyle`.
- The core, theme, cache and hash modules no longer import `react-native`; only the adapters do.
- `em` on `fontSize` is resolved against the parent size on mobile, as in CSS.

See the [changelog](/isoform/project/changelog/) for the full list.
