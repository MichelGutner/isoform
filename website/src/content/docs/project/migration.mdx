The package is published as **`react-isoform`**. The package has changed names more than once, and each rename is a **breaking** change (see the [changelog](/project/changelog/)). Find your current package in `package.json` and follow its section.

## From `@michelgutner/isoform`

<Steps>

1. Swap the dependency:

   ```bash
   npm uninstall @michelgutner/isoform
   npm install react-isoform
   ```

2. Rename every import. This covers the root and the subpaths (`/metro`, `/babel`, `/jsx-runtime`, `/jsx-dev-runtime`):

   ```bash
   grep -rl "@michelgutner/isoform" --exclude-dir=node_modules --exclude-dir=.git . \
     | xargs sed -i '' 's#@michelgutner/isoform#react-isoform#g'
   ```

   On Linux use `sed -i` without the empty `''`.

3. Check the places the search may miss: `jsxImportSource` in your Babel, Vite or TypeScript config, the Babel plugin path (`react-isoform/babel`), the Metro wrapper (`react-isoform/metro`), `tsconfig` `paths`, and any `declare module '@michelgutner/isoform'` used to augment types.

4. On iOS, run `pod install` again: the pod now has the new name.

5. On Android, a custom Gradle reference to the old module name (`:michelgutner_isoform`) becomes `:react-isoform`. Apps that rely on autolinking need no change.

</Steps>

Nothing else changes: `isoform.config.json`, the `isoform-setup-ios` command and the API are the same.

## From `react-native-stylized`

`react-native-stylized` is deprecated on npm. Steps 1 to 3 above apply with `react-native-stylized` as the old name (the native steps only if you use the optional native modules). The same release also changed:

- The `/react-native` subpath export was removed: import everything from the package root.
- `react-native` is now an **optional** peer dependency, `>=0.76` (props such as `paddingInline` and `boxShadow` need React Native 0.76 or newer). `react-dom` is an optional peer too.
- **`when('key:value')` conditions now match exactly.** They used to match by substring, so `when('status:active', …)` also matched `status === 'inactive'`. Review any condition that relied on a partial match.
- `em` on `fontSize` is resolved against the parent size, as in CSS. It used to resolve against itself.
- Web primitives default to `border-style: solid; border-width: 0`, as React Native's border model does.

<Aside type="tip">
After migrating, run your type check and your tests: a leftover import of the old name fails the type check with "Cannot find module".
</Aside>
