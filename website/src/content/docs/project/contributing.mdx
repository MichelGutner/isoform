The full guide is [`CONTRIBUTING.md`](https://github.com/MichelGutner/isoform/blob/main/CONTRIBUTING.md) in the repository. In short:

```bash
git clone https://github.com/MichelGutner/isoform.git
cd isoform
nvm use          # Node from .nvmrc
yarn install
```

| Command | What it does |
|---|---|
| `yarn lint` | ESLint over `src`, `metro.js`, `react-native.config.js` and `scripts` |
| `yarn typecheck` | TypeScript, no output |
| `yarn test` | Jest (core, both adapters, codegen specs) |
| `yarn build` | Compiles `src` to `dist` |
| `yarn check:swift` | Type-checks every iOS module's Swift sources (macOS + Xcode) |

## Running the showcase

The same showcase (`examples/showcase`) runs in two apps that import the library from source:

```bash
cd example && yarn install && yarn ios        # or: yarn android
cd example-web && yarn install && yarn dev    # React DOM + Vite
```

## This documentation site

The site lives in [`website/`](https://github.com/MichelGutner/isoform/tree/main/website) (Astro Starlight). Its live examples import the library from `../src`, like `example-web` does.

```bash
cd website
npm install
npm run dev     # http://localhost:4321/isoform/
npm run build   # also checks every internal link
```

Pages are MDX files under `website/src/content/docs/`; live examples are React components under `website/src/components/demos/`. Every page has an "Edit page" link at the bottom.

## Pull requests

- PRs are squash-merged; the **PR title** follows [Conventional Commits](https://www.conventionalcommits.org) (`feat(image): pinch zoom`, `fix(modal): …`, `docs: …`).
- There is no hosted CI: run `yarn lint`, `yarn typecheck`, `yarn test` and `yarn build` before opening a PR, plus `yarn check:swift` when you touch `ios/`.
- Add or update tests for behavior changes, and these docs for API changes.
- Exported types need English JSDoc on every member.

Releases are published by the maintainer with [semantic-release](https://semantic-release.gitbook.io), which picks the next version from the commit types.
