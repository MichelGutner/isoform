---
title: Instalação
description: Instale o Isoform em um app Expo, em um app React Native puro, ou em um app web com Vite ou Next.js.
---

import { Tabs, TabItem, Steps, Aside } from '@astrojs/starlight/components';

```bash
npm install react-isoform
# ou
yarn add react-isoform
```

As peer dependencies do Isoform são `react >= 18` mais **uma** plataforma:

| Alvo | Instale |
|---|---|
| Web | `react-dom >= 18` |
| Mobile | `react-native >= 0.76` |

`react-dom` e `react-native` são peers opcionais: um app web nunca precisa do React Native e um app mobile nunca precisa do React DOM. `react-native-svg` (`>= 15`) também é um peer opcional, necessário só para o [módulo SVG](/modules/svg/) no mobile.

## Configure o seu app

<Tabs syncKey="platform">
  <TabItem label="Expo">
    <Steps>
    1. Instale o pacote:

       ```bash
       npx expo install react-isoform
       ```

    2. Crie o arquivo de configuração (veja o [Quick start](/pt-br/getting-started/quick-start/)) e importe-o **primeiro** no layout raiz, antes de qualquer renderização:

       ```tsx title="app/_layout.tsx"
       import '../isoform.config';
       ```

    3. Se você usa [módulos opcionais](/getting-started/configuration/), adicione `isoform.config.json` ao lado do `package.json`, envolva a configuração do Metro e refaça o build nativo (`npx expo prebuild` / `npx expo run:ios`):

       ```js title="metro.config.js"
       const { getDefaultConfig } = require('expo/metro-config');
       const { withIsoform } = require('react-isoform/metro');

       module.exports = withIsoform(getDefaultConfig(__dirname));
       ```
    </Steps>
  </TabItem>
  <TabItem label="React Native puro">
    <Steps>
    1. Instale o pacote e os pods do iOS:

       ```bash
       yarn add react-isoform
       cd ios && pod install
       ```

    2. Importe o arquivo de configuração primeiro no `index.js`:

       ```js title="index.js"
       import './isoform.config';
       import { AppRegistry } from 'react-native';
       import App from './App';

       AppRegistry.registerComponent('MyApp', () => App);
       ```

    3. Com módulos opcionais, adicione `isoform.config.json` na raiz do app e envolva a configuração do Metro:

       ```js title="metro.config.js"
       const { getDefaultConfig } = require('@react-native/metro-config');
       const { withIsoform } = require('react-isoform/metro');

       module.exports = withIsoform(getDefaultConfig(__dirname));
       ```

       Rode `cd ios && pod install` de novo sempre que o `isoform.config.json` mudar.
    </Steps>
  </TabItem>
  <TabItem label="Web (Vite)">
    <Steps>
    1. Instale o pacote junto com o React DOM:

       ```bash
       npm install react-isoform react react-dom
       ```

    2. Importe o arquivo de configuração primeiro na entrada:

       ```tsx title="src/main.tsx"
       import './isoform.config';
       import { createRoot } from 'react-dom/client';
       import { App } from './App';

       createRoot(document.getElementById('root')!).render(<App />);
       ```
    </Steps>

    O Vite resolve o provider web do Isoform sozinho. Não precisa de plugin: cada módulo opcional é um chunk separado, baixado só quando o módulo está ligado e um dos seus componentes é renderizado.
  </TabItem>
  <TabItem label="Web (Next.js)">
    <Steps>
    1. Instale o pacote junto com o React DOM:

       ```bash
       npm install react-isoform react react-dom
       ```

    2. Os componentes do Isoform renderizam no cliente. Importe o arquivo de configuração no topo de uma entrada de cliente que envolva a sua árvore (por exemplo, um arquivo de providers com `'use client'` usado pelo layout raiz), para que `configure()` rode antes da primeira renderização.

    3. Para renderizar os estilos no servidor, colete-os com [`getStyleText()`](/guides/server-side-rendering/) e injete-os em uma tag `<style>`.
    </Steps>
  </TabItem>
</Tabs>

<Aside type="caution" title="Importe a configuração antes de qualquer renderização">
Os componentes podem ser **definidos** antes de `configure()` rodar (eles só guardam o nome de uma primitiva), mas `configure()` precisa rodar antes da primeira **renderização**. Importe o arquivo de configuração no topo da entrada do app.
</Aside>
