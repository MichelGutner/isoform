<CardGrid>
  <Card title="Uma biblioteca de componentes" icon="laptop">
    `engine('Box')`, `engine('Pressable')`… viram um `div` na web e uma `View` no mobile. Sem checagem de plataforma nos seus componentes.
  </Card>
  <Card title="Vocabulário CSS padrão" icon="pencil">
    `paddingInline`, `boxShadow`, `'1rem'`, `transform: 'rotate(-2deg)'`. Números são px, strings são CSS, em todas as plataformas.
  </Card>
  <Card title="Tema global, sem providers" icon="star">
    `configure({ theme })` uma vez na inicialização, `updateTheme()` em qualquer lugar. Todos os componentes re-renderizam e nada envolve a sua árvore.
  </Card>
  <Card title="Variantes sem boilerplate" icon="list-format">
    `when('props:variant=ghost')`, `when('state:pressed')`, `when('breakpoints:md')`, `when('platform:web')`, `when('::before')`.
  </Card>
  <Card title="Animações nos dois runtimes" icon="rocket">
    `keyframes()` e `transition` do CSS viram CSS de verdade na web e `Animated` no React Native.
  </Card>
  <Card title="Módulos nativos opcionais" icon="puzzle">
    Vídeo, áudio, PDF, bottom sheet, SVG, câmera, seletor de data, pipeline de imagem e modal, desenhados com UIKit/SwiftUI e Jetpack Compose. Desligados por padrão, sem custo quando desligados.
  </Card>
</CardGrid>
