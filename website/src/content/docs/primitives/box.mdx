`Box` is the layout container: a `<div>` with React Native defaults (flex column) on the web, a `View` on mobile.

```tsx
const Row = engine('Box', { flexDirection: 'row', gap: 12, alignItems: 'center' });
```

## Props

`BoxProps` = the `<div>` DOM props (minus `style`, `onChange` and `autoCorrect`) + the [shared props](/primitives/overview/#props-every-primitive-shares) + `IsoNativeProps`.

## Web defaults

On the web `Box` starts as `display: flex; flex-direction: column`, with `border-style: solid` and `border-width: 0`, so layouts behave as they do in React Native and `borderWidth` alone draws a border. These defaults are low-priority base rules: any style you set wins.

| | Web | Mobile |
|---|---|---|
| Element | `<div>` | `View` |
| Default direction | column | column |
| `flex: 1` | `1 1 0%` (React Native semantics) | native |
| Legacy name | `View` (deprecated) | `View` (deprecated) |
