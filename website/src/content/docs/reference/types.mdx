Every type below is exported from `@michelgutner/isoform` and documented with JSDoc in the source, so editors show the same descriptions.

```ts
import type { EngineComponent, IsoStyle, VideoHandle } from '@michelgutner/isoform';
```

## Core

| Type | Description |
|---|---|
| `Engine` | The type of `engine()`, with its three overloads. See [`engine()`](/reference/engine/). |
| `EngineComponent<C, P>` | A component created by `engine()`. See [`EngineComponent`](/reference/engine-component/). |
| `BaseStyleContext<P>`, `StyleContext<P>` | `{ theme, props, platform }`, passed to style and condition functions (`platform` is always resolved in `StyleContext`). |
| `EngineTheme` | Your app's theme shape, declared globally. See [TypeScript](/guides/typescript/#typing-your-theme). |
| `Keyframes` | The frames passed to [`keyframes()`](/reference/keyframes/). |
| `PlatformAdapter`, `ApplyPropsInput`, `StateStyles` | The provider interface. See [`PlatformAdapter`](/reference/platform-adapter/). |

## Configuration

| Type | Description |
|---|---|
| `ConfigureOptions` | Options of [`configure()`](/reference/configure/). |
| `ProviderName` | `'react-native' \| 'react'`. |
| `IsoModules` | The optional modules and their settings. |
| `ModuleName` | `'video' \| 'audio' \| 'pdf' \| 'sheet' \| 'svg' \| 'camera' \| 'datePicker' \| 'image' \| 'modal'`. |
| `ModuleOptions` | `{ enabled?: boolean }`, accepted by every module. |
| `AudioModuleOptions` | `+ mediaSession?: boolean` (build-time only). |
| `PdfModuleOptions` | `+ workerSrc?: string` (web only). |
| `CameraModuleOptions` | `+ video?: boolean`, `codeScanner?: boolean`. |

## Conditions

| Type | Description |
|---|---|
| `Condition<P>` | Anything `when()` accepts: a condition string, `(ctx) => boolean`, a boolean, or another string (custom breakpoint ranges; unknown conditions warn in development). |
| `Platform` | `'ios' \| 'android' \| 'web' \| 'native'`. |
| `PlatformCondition` | `` `platform:${Platform}` ``. |
| `StateName` | `'hover' \| 'focus' \| 'focus-visible' \| 'pressed'`. |
| `StateCondition` | `` `state:${StateName}` ``. |
| `PropConditionKeys<P>` | The `'props:…'` conditions derived from custom props `P`. |
| `PseudoName` | Every pseudo-element (`UniversalPseudoName` plus the web-only ones). |
| `IsoBreakpointNames` | Augment it to type your own breakpoint names. |
| `BreakpointName` | `'sm' \| 'md' \| 'lg' \| 'xl'` plus augmented names. |
| `BreakpointCondition` | `` `breakpoints:${BreakpointName}` ``. |
| `BreakpointRangeCondition` | `'breakpoints:<md'`, `'breakpoints:md..lg'`… |
| `DefaultBreakpointRange` | The valid ascending ranges between the default breakpoints. |

## Style

| Type | Description |
|---|---|
| `IsoStyle` | The universal style: full `React.CSSProperties` (with `transform` as a CSS string or a React Native array), the legacy React Native aliases and CSS custom properties (`--name`, web only). See [Style vocabulary](/guides/style-vocabulary/). |
| `StyleInput` | What the `style` prop accepts: an `IsoStyle`, a falsy value, or a nested array of those. |
| `LegacyRNStyle` | React Native aliases kept for compatibility (`paddingHorizontal`, `shadow*`, `elevation`, `resizeMode`, `tintColor`…), each marked with its CSS replacement. |

## Primitives

| Type | Description |
|---|---|
| `IsoPrimitives` | Primitive name → props: what `engine('Name')` accepts. |
| `IsoNativeProps` | Augment it to type native props the lib does not list. |
| `BoxProps`, `TextProps`, `PressableProps`, `InputProps`, `ImageProps`, `ScrollProps` | Props of the universal primitives. See [Primitives](/primitives/overview/). |
| `VideoProps`, `AudioProps`, `PdfProps`, `BottomSheetProps`, `CameraProps`, `DatePickerProps`, `ModalProps`, `SvgProps`, `SvgElementProps` | Props of the module primitives. |

## Media (video, audio, playlists)

| Type | Description |
|---|---|
| `PlaybackProps` | Props shared by `Video` and `Audio`. See [Video](/modules/video/). |
| `VideoOwnProps`, `AudioOwnProps` | Each player's own props. |
| `MediaHandle`, `VideoHandle`, `AudioHandle` | The players' `ref`. |
| `MediaTime` | `{ currentTime, duration }` from `onTimeUpdate`. |
| `MediaInfo` | `{ duration, width, height }` from `onLoad`. |
| `PlaylistItem`, `VideoItem`, `AudioItem`, `PdfItem` | Entries of an `items` list. See [Playlists](/modules/playlists/). |
| `PlaylistProps`, `MediaPlaylistProps` | List props (`items`, `initialIndex`, `carousel`, `onItemChange`, `autoAdvance`). |
| `PlaylistChange` | `{ index, item }` from `onItemChange`. |
| `PlaylistHandle` | `next()`, `previous()`, `goTo(index)`. |

## PDF

`PdfOwnProps`, `PdfHandle`, `PdfFit` (`'width' | 'page'`), `PdfDirection` (`'vertical' | 'horizontal'`), `PdfLoadInfo`, `PdfPageInfo`, `PdfSearchInfo`. See [PDF viewer](/modules/pdf/).

## Bottom sheet

`BottomSheetOwnProps`, `BottomSheetHandle`, `SheetDetent` (`'fit' | 'full' | number | '${number}%'`), `SheetDetentChange`. See [Bottom sheet](/modules/sheet/).

## Camera

`CameraOwnProps`, `CameraHandle`, `CameraFacing`, `CameraFlash`, `CameraPermission`, `CameraPermissionStatus`, `CameraCode`, `CameraCodeType`, `CameraPhoto`, `CameraVideo`, `TakePhotoOptions`. See [Camera](/modules/camera/).

## Date picker

`DatePickerOwnProps`, `DatePickerMode` (`'date' | 'time' | 'datetime'`), `DatePickerDisplay` (`'inline' | 'wheel' | 'compact'`). See [Date picker](/modules/date-picker/).

## Image

`ImageOwnProps`, `ImageHandle`, `ImageSource`, `ImageSourceInput`, `ImageContentFit`, `ImageContentPosition`, `ImageCachePolicy`, `ImageCacheType`, `ImagePriority`, `ImageLoadEvent`, `ImageProgressEvent`, `ImageErrorEvent`, `ImageZoomEvent`, `ImageZoomOptions`, `PrefetchOptions`, `ClearImageCacheOptions`. See [Image pipeline](/modules/image/).

## Modal

`ModalOwnProps`, `ModalPresentation` (`'dialog' | 'fullScreen'`), `ModalAnimation` (`'scale' | 'slide' | 'fade' | 'none'`). See [Modal](/modules/modal/).
