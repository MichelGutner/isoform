```ts
type EngineComponent<C extends ComponentType<any>, P extends object = {}> =
  ForwardRefExoticComponent<ComponentPropsWithRef<C> & P> & {
    when(condition, attrs): EngineComponent<C, P>;
    attrs(attrs): EngineComponent<C, P>;
    style(style): EngineComponent<C, P>;
    extend(): EngineComponent<C, P>;
  };
```

An `EngineComponent` renders `C` with the accumulated rules. Its methods add rules and return a component to keep chaining.

## `.style(style)`

Adds a style: an object, or a function of `{ theme, props, platform }`. Later styles override earlier ones (last wins).

```tsx
engine('Box').style({ padding: 12 }).style(({ theme }) => ({ backgroundColor: theme.color.surface }));
```

## `.when(condition, attrs)`

Applies props (including `style`) only when `condition` holds.

| Parameter | Description |
|---|---|
| `condition` | A platform (`'platform:ios'`, `'platform:web'`…), a state (`'state:hover'`, `'state:pressed'`…), a breakpoint (`'breakpoints:md'`, `'breakpoints:<md'`, `'breakpoints:sm..lg'`), a prop (`'props:disabled'`, `'props:variant=primary'`), a pseudo-element (`'::before'`…), a function `(ctx) => boolean`, or a boolean. |
| `attrs` | The props to apply, or a function of `{ theme, props, platform }` returning them. State, breakpoint and pseudo-element conditions only use `{ style }`. |

See [Conditions and variants](/guides/conditions/).

## `.attrs(attrs)`

Applies props unconditionally (a default `role`, `type`, `testID`…). `attrs` may include a `style`.

## `.extend()`

Clones the current rules into a **new** component, to build a variation without touching the original.

```tsx
const Tag = engine('Box', { padding: 8 });
const DangerTag = Tag.extend().style({ backgroundColor: 'crimson' });
```

:::caution
`.style()`, `.when()` and `.attrs()` add the rule to the component they are called on. Branch with `.extend()` (or `engine(Tag, style)`) when the original must stay as it is.
:::

## Props

An engine component accepts the props of `C` plus the custom props `P`, plus:

- `style`: always wins over the rules (applied inline on the web);
- `ref`: forwarded to the base component (typed with the primitive's handle when it has one).
