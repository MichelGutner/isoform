---
title: stylized()
description: The builder behind engine(). Not part of the public entry; use engine().
---

`stylized(component)` is the internal builder function that `engine()` is built on (`src/core/builder.ts`). It is **not exported** from `isoform`'s public entry, so apps cannot import it:

```ts
import { stylized } from 'isoform'; // ✗ not exported
```

Use [`engine()`](/reference/engine/) instead. It takes the same kinds of base component (a primitive name or any React component), accepts an initial style, returns a ready component with `ref` forwarding, and adds the chainable `.style()`, `.when()`, `.attrs()` and `.extend()` methods.

| Need | Use |
|---|---|
| Style a primitive | `engine('Box', style)` |
| Style any React component | `engine(MyComponent, style)` |
| Build on another styled component | `engine(OtherEngineComponent, style)` or `.extend()` |

Coming from `react-native-stylized`? See [Migration](/project/migration/).
