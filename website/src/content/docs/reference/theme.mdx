The theme is a global store compatible with React's `useSyncExternalStore`. No provider is needed.

## `updateTheme(themeOrFn)`

Deep-merges a partial theme into the current one and notifies every subscriber, so every component that reads the theme re-renders.

```ts
updateTheme({ color: { primary: '#f43f5e' } }); // deep merge
updateTheme((prev) => ({ spacing: { md: prev.spacing.md * 1.25 } })); // a function of the previous theme
```

A function receives the current theme and returns the partial theme to merge.

`configure({ theme })` is a shortcut for `updateTheme(theme)`.

## `useTheme()`

A reactive hook (`useSyncExternalStore`): returns the current theme and re-renders the component when it changes. Concurrent-safe and Strict Mode compatible.

```tsx
const theme = useTheme();
return <Text style={{ color: theme.color.primary }}>Hi</Text>;
```

## `getTheme()`

Returns the current theme outside React (event handlers, utilities). Inside a server render started with `runWithTheme()`, it returns that request's theme.

## `runWithTheme(theme, render)`

```ts
import { runWithTheme } from 'react-isoform/server';

function runWithTheme<R>(theme: EngineTheme, render: () => R): R;
```

Server only (Node). Renders with `theme` instead of the global theme, per request, without a provider. See [Server-side rendering](/guides/server-side-rendering/#a-theme-per-request).

## `EngineTheme`

The global type of your theme, `unknown` until your app declares it. See [TypeScript](/guides/typescript/#typing-your-theme).
