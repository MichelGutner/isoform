---
title: getStyleText()
description: Returns the CSS generated so far, to inject into a server-rendered style tag.
---

```ts
function getStyleText(): string;
```

SSR (web): returns the CSS generated so far (atomic classes, state and breakpoint rules, `@keyframes`), to inject into a `<style>` on the server. On platforms that do not generate CSS (mobile) it returns `''`.

```tsx
import { getStyleText } from 'react-isoform';

<style data-isoform="ssr" dangerouslySetInnerHTML={{ __html: getStyleText() }} />;
```

See [Server-side rendering](/guides/server-side-rendering/).
