```ts
function configure(options?: ConfigureOptions): void;
```

Configures Isoform: provider, theme, breakpoints, native conversion and optional modules. Call it once, when the app starts, before the first render.

```ts
import { configure } from '@michelgutner/isoform';
import isoform from './isoform.config.json';

configure({ theme: tokens, modules: isoform.modules });
```

## `ConfigureOptions`

| Option | Type | Default | Description |
|---|---|---|---|
| `provider` | `'auto' \| ProviderName \| PlatformAdapter` | `'auto'` | `'auto'`: the provider the bundler included (React Native on Metro, React DOM on Vite/Next/webpack). `'react-native'` / `'react'`: explicit; throws a clear error if it does not match the bundle. A [`PlatformAdapter`](/reference/platform-adapter/): a custom platform. |
| `theme` | `Partial<EngineTheme>` | | The theme. Shortcut for `updateTheme(theme)`. |
| `breakpoints` | `Record<string, number>` | `{ sm: 480, md: 768, lg: 1024, xl: 1280 }` | Minimum widths (px), mobile-first. Replaces the whole set. Augment `IsoBreakpointNames` to type new names. |
| `native` | `{ remBase?: number }` | `{ remBase: 16 }` | Pixel size of `1rem` (and the fallback for `em`) on native. |
| `modules` | `IsoModules` | all off | Optional modules: `video`, `audio`, `pdf`, `sheet`, `svg`, `camera`, `datePicker`, `image`, `modal`. Each is `boolean` or an options object with `enabled`. |

`ProviderName` is `'react-native' | 'react'`.

## `IsoModules`

| Key | Type | Options |
|---|---|---|
| `video` | `boolean \| ModuleOptions` | `enabled` |
| `audio` | `boolean \| AudioModuleOptions` | `enabled`, `mediaSession` (build-time only) |
| `pdf` | `boolean \| PdfModuleOptions` | `enabled`, `workerSrc` (web only) |
| `sheet` | `boolean \| ModuleOptions` | `enabled` |
| `svg` | `boolean \| ModuleOptions` | `enabled` |
| `camera` | `boolean \| CameraModuleOptions` | `enabled`, `video`, `codeScanner` |
| `datePicker` | `boolean \| ModuleOptions` | `enabled` |
| `image` | `boolean \| ModuleOptions` | `enabled` |
| `modal` | `boolean \| ModuleOptions` | `enabled` |

A module is on only with `true` or `{ enabled: true }`. Modules you leave out of `modules` are off.

## Errors

`configure()` throws when:

- `provider: 'auto'` is used but no provider was bundled (pass an adapter);
- an explicit provider name is not the one in the bundle;
- a breakpoint name is invalid (it must match `[A-Za-z_][\w-]*`), reserved (`ios`, `android`, `web`, `native`, `hover`, `focus`, `focus-visible`, `pressed`), or its width is not a number ≥ 0.

Switching providers after the first render logs a development warning.

## `getProvider()`

```ts
function getProvider(): PlatformAdapter;
```

Returns the active platform adapter (the one chosen by `configure`, or the bundled one). Mostly useful to adapters and tests.
