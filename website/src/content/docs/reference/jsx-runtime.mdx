## `react-isoform/jsx-runtime`

The automatic JSX runtime (`jsx`, `jsxs`, `Fragment`, and `jsxDEV` in `/jsx-dev-runtime`), selected with `jsxImportSource: 'react-isoform'`.

For a styled component whose style never reads the theme, it creates the element that component would render (the component underneath, with its final props) instead of the styled component itself. Every other element goes to `react/jsx-runtime` unchanged. Its `JSX` types are React's.

The package root also exports `createElement` (React's), because JSX compilers import it from the `jsxImportSource` root for `<C {...props} key={k} />`.

## `react-isoform/babel`

```js
plugins: ['react-isoform/babel'];
```

In files that import from `react-isoform`, wraps in `themeFree()` the functions passed to `engine()`, `.style()`, `.when()` and `.attrs()` (and `style` functions inside attrs objects) that provably cannot read the theme. No options.

## `themeFree()`

```ts
function themeFree<F extends (...args: any[]) => any>(fn: F): F;
```

Marks a style function, `when()` condition or attrs function as never reading the theme, and returns the same function. A styled component is rendered without its wrapper when every function in its rules is marked (a static style needs no mark).

```ts
import { engine, themeFree } from 'react-isoform';

const Cell = engine<'Box', { size: number }>('Box', themeFree(({ props }) => ({ width: props.size })));
```

In development, a marked function that reads the theme logs a warning.

## `performance.inline`

```ts
configure({ performance: { inline: false } });
```

`true` by default. `false` keeps every styled component's wrapper even with the JSX runtime. Set it once, at startup.
