<CardGrid>
  <Card title="One component library" icon="laptop">
    `engine('Box')`, `engine('Pressable')`… resolve to a `div` on the web and a `View` on mobile. No platform checks in your components.
  </Card>
  <Card title="Standard CSS vocabulary" icon="pencil">
    `paddingInline`, `boxShadow`, `'1rem'`, `transform: 'rotate(-2deg)'`. Numbers are px, strings are CSS, on every platform.
  </Card>
  <Card title="Global theme, no providers" icon="star">
    `configure({ theme })` once at startup, `updateTheme()` anywhere. Every component re-renders, nothing wraps your tree.
  </Card>
  <Card title="Variants without boilerplate" icon="list-format">
    `when('props:variant=ghost')`, `when('state:pressed')`, `when('breakpoints:md')`, `when('platform:web')`, `when('::before')`.
  </Card>
  <Card title="Animations on both runtimes" icon="rocket">
    `keyframes()` and CSS `transition` become real CSS on the web and `Animated` on React Native.
  </Card>
  <Card title="Optional native modules" icon="puzzle">
    Video, audio, PDF, bottom sheet, SVG, camera, date picker, image pipeline and modal, drawn with UIKit/SwiftUI and Jetpack Compose. Off by default, zero cost when off.
  </Card>
</CardGrid>
