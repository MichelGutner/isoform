## Chaining rules

An engine component exposes four chainable methods. Each returns a component you can keep chaining:

| Method | What it adds |
|---|---|
| `.style(objectOrFn)` | A style; later styles override earlier ones (last wins). |
| `.when(condition, attrs)` | Props or style applied when the condition holds. See [Conditions](/guides/conditions/). |
| `.attrs(props)` | Props applied on every render (a default `role`, `type`, `testID`…). |
| `.extend()` | A copy of the current rules, to branch a variation. |

<Aside type="caution" title="Chain at definition time; branch with extend()">
`.style()`, `.when()` and `.attrs()` add the rule to the component they are called on and return it. To build a variation **without changing the original**, call `.extend()` first: it copies the rules into a new component.

```tsx
const Tag = engine('Box', { padding: 8 });
const DangerTag = Tag.extend().style({ backgroundColor: 'crimson' }); // Tag is unchanged
```
</Aside>

## Building on another engine component

Pass an engine component to `engine()` to inherit its rules **and its custom props**, then add more:

```tsx
const Button = engine<'Pressable', { variant?: 'primary' | 'ghost' }>('Pressable', { padding: 12 })
  .when('props:variant=ghost', { style: { backgroundColor: 'transparent' } });

// inherits `variant`, adds `size`
const IconButton = engine<typeof Button, { size?: 'sm' | 'lg' }>(Button, { borderRadius: 999 })
  .when('props:size=lg', { style: { padding: 20 } });

<IconButton variant="ghost" size="lg" />;
```

## Wrapping any React component

`engine()` also styles any React component, including third-party ones. It receives the style through its `style` prop on native, and `className` + `style` on the web:

```tsx
import { Link } from 'expo-router';

const NavLink = engine(Link, ({ theme }) => ({ color: theme.color.primary, fontWeight: '600' }));
```

## Fixed props with `attrs`

```tsx
const SearchField = engine('Input', { paddingInline: 12 }).attrs({
  type: 'search',
  'aria-label': 'Search',
  autoCorrect: false,
});
```

`attrs` can carry a `style` too; it is merged in order with the other rules. A `ref` set through `when(…, { ref })` or `attrs({ ref })` is forwarded to the base component.
